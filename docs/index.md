# ForgeText Docs

This folder backs the public GitHub Pages site and the in-repository product docs.

ForgeText is currently documented as a Studio-first native editor with:

- raw-first editing defaults for structured files
- a calm four-section sidebar and optional Engineering Workbench
- `Workbench + Advanced` runtime, privacy, and safety controls
- signed managed enterprise policy, private catalogs, update rings, and encrypted local audit controls
- local-first AI provider setup with cloud and local-model flows
- Sparkle/GitHub Release update guidance

- [Help](./HELP.md): ForgeText 1.2.1 feature guide, trust model, and common workflows
- [Engineering Workbench](./ENGINEERING_WORKBENCH.md): health, code navigation, Git review, tests, remotes, investigations, data, AI change sets, and profiles
- [Enterprise Editor Platform](./ENTERPRISE_EDITOR_PLATFORM.md): performance, protocol runtimes, GitHub, containers, policy, and explicit product boundaries
- [Managed Policy](./MANAGED_POLICY.md): enterprise admin controls, file locations, and sample policy
- [Enterprise Deployment](./ENTERPRISE_DEPLOYMENT.md): MDM forced preferences, private catalogs, update channels, and fleet validation
- [Security Hardening](./SECURITY_HARDENING.md): trust boundaries, process/network/file controls, plugin signing, release security, and residual risks
- [Security Policy](../SECURITY.md): supported-version and private vulnerability-reporting guidance
- [Product Gap Audit](./PRODUCT_GAP_AUDIT.md): closed roadmap gaps and the remaining hosted/debug/scale boundaries
- [Updates](./UPDATES.md): Sparkle, appcast, DMG, and GitHub Releases setup
- [Roadmap](./ROADMAP.md): completed app-side roadmap and the next validation cycle
- [UI Workbench Plan](./UI_WORKBENCH_PLAN.md): Studio-first workbench direction and UI principles
- [Appcast](./appcast.xml): public Sparkle update feed
